周期

≥2 才算转弱
指标 数据源 亮灯规则
1 合同价 / ASP 公司 10-Q / 业绩：DRAM·NAND·HBM ASP%；TrendForce / DRAMeXchange 合同价 QoQ 见顶后连续走平或下跌（涨幅变慢一季不算）。注明 as_of 与 period
2 出货 vs 价格 量：公司 bit shipments（bits QoQ/YoY）；缺位用行业 bits 旁证。价：同期 ASP 或合同价 bits 升且价跌/走平转跌。只有营收、无量价拆分 → 不算
3 成品库存 FG 10-Q Note Inventories：Finished goods（$），对比上季 QoQ FG 连续回升（≥2 季）。总库存或 WIP → 不算
4 终端谁拿到货 10-Q 分部：MCBU / 手机·PC bits 与 CMBU / 数据中心表述 手机/PC bits 回升，且上下文为供给宽松/余货，非需求强劲。引用原句

旁证（不单独计灯）：韩国内存出口 kg 升且 $/kg 掉，与合同价同向时加强。
